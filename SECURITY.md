# Security policy

AegisGraph is a local investigation demonstration with entirely synthetic data.
Do not expose this application to the public internet. The local analyst identity
is a development assumption, not enterprise authentication or authorization.

Report suspected vulnerabilities privately through this repository's GitHub
security advisory feature when enabled. Do not include real credentials, customer
data, or weaponized proof-of-concept payloads in public issues.

See [the threat model](docs/threat-model/THREAT_MODEL.md) for implemented controls,
residual risks, and the prerequisites for production deployment.
