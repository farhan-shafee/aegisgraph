# ADR-004: Validate citations and claim support

- Status: Accepted
- Date: 2026-09-17

## Context

Plausible prose and syntactically valid citations can still be unsupported. An event from another case must not become admissible evidence.

## Decision

Every model-derived factual finding carries current-case, in-context evidence IDs. Validate schema, membership, and exact typed claim support sets. Reject the whole answer when any claim is invalid and render accepted facts through deterministic templates. Derive the cited summary from those same accepted findings; do not accept arbitrary model-written prose. Human-authored findings have a separate review workflow and citation-membership checks, not a general semantic fact checker.

## Consequences

Outputs are less expressive but more auditable. Citation checks do not prove the input telemetry is truthful or establish attacker identity. The hypothesis vocabulary is deliberately narrow; the qualitative confidence label is not a calibrated probability. New claim types need tests and explicit predicates. Analyst-benign rows are excluded before model context selection and cannot support a suspicious hypothesis; the result discloses their count.

## Alternatives considered

Allowing arbitrary cited prose would permit citation laundering; an extra model judge would add uncertainty rather than deterministic enforcement.
