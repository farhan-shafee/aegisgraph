# ADR-003: AI cannot mutate incident state

- Status: Accepted
- Date: 2026-09-17

## Context

A provider may misunderstand a question, follow injected instructions, or return malformed output. Model intent is not authorization.

## Decision

Give providers only a question, current incident identifier, bounded projected evidence, and supported claim candidates. Expose no database, retrieval, command, or mutation tools. Status, ownership, findings and report approval require explicit analyst API actions. The external API transport holds its provider credential; that credential is never model context.

## Consequences

AI can assist analysis without becoming the system of record. Recommendations are advisory. The single local demo analyst can access all cases; scope validation is not a production user-authorization system. A future action agent would need a separate permission and approval architecture.

## Alternatives considered

Prompting a tool-capable model to ask permission would leave the enforcement boundary inside the model.
