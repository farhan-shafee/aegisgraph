# ADR-005: Telemetry is untrusted input

- Status: Accepted
- Date: 2026-09-17

## Context

An attacker may control usernames, HTTP metadata, process strings, and embedded text. Such fields may contain instructions directed at the analyst model.

## Decision

Validate and preserve observations as data. Project only bounded allowed fields into provider context; separate instructions from serialized telemetry; validate returned claims independently of prompting. Omit raw source text, free-form metadata, annotations, user agents, and endpoint strings from model context. Use exact typed signal checks instead of converting arbitrary strings into truthy values.

## Consequences

Unneeded raw metadata is excluded from model context while source evidence remains inspectable. Injection fixtures exercise the boundary. Live-provider behavioral robustness remains a distinct evaluation task.

## Alternatives considered

Concatenating raw logs into a system prompt would promote adversarial content into a trusted instruction channel.
