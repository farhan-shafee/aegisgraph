# ADR-002: Separate detection from correlation

- Status: Accepted
- Date: 2026-09-17

## Context

A suspicious observation can be weak by itself, and multiple rules can identify the same sequence. Treating every alert as an incident obscures the engineering distinction.

## Decision

Detection emits evidence-backed alerts. A separate deterministic correlation service groups alerts by principal and event time: at least three distinct rules across at least two rule-ID families in a cluster spanning at most 30 minutes from its first alert. It adds nearby same-principal observations and alert-cited evidence. Session, device, and IP relationships are investigation context, not grouping predicates; particular temporal detection rules separately enforce same-session conditions.

## Consequences

Rules can be tested independently of incident grouping. Correlation can evolve without changing source normalization. Shared identity and time can still join benign activity; analysts retain relevance annotations. Generic rule combinations receive generic summaries, so the flagship account-compromise hypothesis is not applied to cases lacking its supporting rule mix.

## Alternatives considered

One combined scoring function would conceal both rule meaning and grouping reasons.
