# ADR-009: Deterministic reports and explicit review state

- Status: Accepted
- Date: 2026-09-17

## Context

A report must preserve evidence references and make human approval visible. A prior approval must not silently apply after the underlying case changes.

## Decision

Generate the report with a deterministic template, not an AI-written narrative. Include current-case evidence, entities, workflow state, and analyst-approved findings. Start each generated report as a draft. Case edits, evidence annotations, findings, finding review, and notes mark an existing report stale, clear approval metadata, and record invalidation. Reject approval of a stale report until it is regenerated and reviewed.

## Consequences

The model cannot approve or write a report. Human-authored findings still require judgment; citation membership does not prove their narrative. V1 stores one current report and lifecycle audit events, not immutable report-version snapshots. External copies do not automatically reflect later invalidation. A workflow approval records the analyst action, not proof that every statement was read.

## Alternatives considered

Allowing a model to freely compose a report would require an additional factual-support boundary. Keeping approval after case changes would conceal stale evidence or interpretation.
