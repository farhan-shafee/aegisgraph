# ADR-006: Relational entity graph

- Status: Accepted
- Date: 2026-09-17

## Context

The useful V1 graph consists of incident-scoped users, devices, IPs, sessions, roles, services, endpoints and resources linked by observations.

## Decision

Store entities and event relationships relationally and derive the incident graph from evidence-backed associations. Show an accessible entity list alongside the visual representation.

## Consequences

No extra database or synchronization layer is required. Deep cross-tenant graph traversals and large-scale graph analytics are outside V1; reconsider if those become measured requirements.

## Alternatives considered

Neo4j would be appropriate for some future graph workloads but adds operational scope without improving this bounded case view.
