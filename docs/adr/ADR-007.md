# ADR-007: Deterministic correlation before model-based grouping

- Status: Accepted
- Date: 2026-09-17

## Context

The flagship sequence must reproduce under the same seed, and an interviewer should be able to inspect exactly why alerts belong to a case.

## Decision

Use principal identity, a 30-minute cluster anchored at the first alert, and explicit rule-diversity conditions. Parse timestamps before ordering so different valid timezone offsets cannot widen the cluster. Device, session, and IP associations are supporting investigation context. Keep the model downstream of persisted case/evidence construction.

## Consequences

Grouping is reproducible and testable with boundary cases. It will miss patterns outside the encoded logic and is not a generalized incident classifier. False merges and splits require dataset-level evaluation.

## Alternatives considered

Model-based correlation would make evidence scope non-deterministic and conflate detection, authorization, and narrative reasoning.
