# ADR-001: PostgreSQL for V1

- Status: Accepted
- Date: 2026-09-17

## Context

The demonstration needs indexed event queries, evidence joins, transactional analyst changes, and ordinary operational tooling over thousands of events.

## Decision

Use PostgreSQL as the primary database. Use SQLAlchemy for parameterized queries and Alembic for schema history. Keep SQLite as a local/test convenience.

## Consequences

One database keeps transactions and deployment understandable. Text search and huge analytical scans are limited; introduce a search index only after measuring a query workload that PostgreSQL cannot reasonably satisfy.

## Alternatives considered

Elasticsearch would add another storage model, synchronization problem, and service without a demonstrated V1 need.
